1. 需求上下文

1.1 原始需求

给 cc-sesh 的 picker 做两件事：把 Claude 状态表的左右两侧撑开，让 ATTN IDLE RUN WAIT 徽章区成为视觉上独立的一块；给 session 加折叠 / 展开，展开后能看到里面的 window 列表，光标停在哪一行，右侧分栏就显示那一屏的画面，回车可以直接落到具体 window。附带：搜索关键词同时匹配 window 名（命中则该 session 临时展开）、展开状态本地持久化（与 ATTN 同款存储但独立文件）、README hotkey 表补 3 个按键。
