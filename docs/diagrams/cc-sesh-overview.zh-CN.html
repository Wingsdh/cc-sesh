cc-sesh

你的 Claude Code 多会话调度台

在多个 tmux session 里并行跑 Claude Code，picker 一眼看见每个的实时状态——决定下一个该去看谁。

在 tmux 里这样唤出 prefix+t → popup 弹出 不用再 attach 进每个 session 检查状态
cc-sesh picker 1 2 3
1ATTN · 粘性提醒（核心）
"活跑完了？我刚刚让它做的那件事"
某 session 完成 busy → idle 的瞬间，ATTN ● 亮起、"needs you" 分组把它顶到列表最上方、done 1m ago 时间戳贴在行尾——独立于当前状态的提醒，attach 进去后才消失。
2每实例计数 + 状态分布
"一个 session 里跑了几个 Claude，分别在干什么"
4 列计数：ATTN 完成提醒 · IDLE 空闲等命令 · RUN 运行中（busy + subagent）· WAIT 等 OAuth/权限授权——一行内可同时有多个 Claude 实例。
3上游 sesh 多源全保留
"tmux + zoxide + configs + tmuxinator"
底下这一段就是上游 sesh 的 zoxide 历史路径 list——session 来源、命名策略、配置体系一并继承，cc-sesh 只在上面**加一层** Claude 状态。
