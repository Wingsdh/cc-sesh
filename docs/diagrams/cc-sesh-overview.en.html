cc-sesh

Mission control for parallel Claude Code agents

Spin up Claude Code in many tmux sessions at once — the picker shows every agent’s live status, so you know who to attend to next.

Bind it in tmux prefix+t → opens a popup No more attaching into every session to check
cc-sesh picker 1 2 3
1ATTN · Sticky reminder (the point)
“Did the thing I told it to do actually finish?”
The instant a session finishes a busy → idle transition, ATTN ● lights up, the “needs you” group pins it to the top, and a done 1m ago timestamp gets stamped on the row — a sticky reminder independent of current state, dismissed only when you attach in.
2Per-instance counts & state mix
“How many Claudes are in this session, doing what?”
Four columns of live counts: ATTN done-and-waiting · IDLE sitting idle · RUN actively working (busy + subagent) · WAIT blocked on OAuth / permission — a single row may hold many Claude instances at once.
